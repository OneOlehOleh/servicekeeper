# МотоЖурнал (MotoLedger) — Сервисный журнал гаража

Автономное (PWA / Offline) мобильное веб-приложение для ведения сервисного учета техники с гибридными типами наработки:
- **Моточасы (м/ч)** — для эндуро, питбайков, катеров, лодочных моторов (ПЛМ) и садовой техники.
- **Пробег (км)** — для дорожных мотоциклов и автомобилей.
- **Временные интервалы (месяцы)** — для сезонной консервации и регламентов (тормозная жидкость, антифриз).

---

## Возможности MVP

1. **Гараж и парк техники**:
   - Предзаполненные реальные карточки: **BMW F800GS**, **BMW F800R**, **Berkut S-DX (Parsun 40 FETS)**, **BRZ 250 Enduro**, **Apollo Freerider 150**, **Yamaha 25 FHMS (2Т)**, **Автомобиль**, **Садовый трактор / генератор**.
   - Фильтрация по категориям (Дорожные, Эндуро/Пит, Водная техника, Авто, Сад).
   - Быстрое обновление показаний счетчика в один тап (`+1 м/ч` или `+500 км`).

2. **Баннер срочных ТО**:
   - Автоматический расчет остатка моточасов / километров / месяцев.
   - Выделение красным (просрочено) и желтым (скоро ТО) цветами.
   - Прямой переход к проведению ТО.

3. **Шпаргалка гаража (в 1 тап)**:
   - Моторное масло: вязкость, спецификации (API, JASO), точный объем картера.
   - Масло в редуктор / дейдвуд (для ПЛМ).
   - Топливная смесь (для 2Т моторов, напр. 1:50).
   - Масляный и воздушный фильтры.
   - Маркировка свечей зажигания и зазор.
   - Моменты затяжки сливных пробок.
   - Давление в шинах и баллонах.

4. **Быстрое внесение ТО («Грязные руки»)**:
   - Крупные сенсорные переключатели.
   - Автовыбор просроченных регламентов.
   - Кнопка **«Вставить из шпаргалки»** (автоматически подставляет марки масел и фильтров без необходимости печатать на клавиатуре).
   - Автоматический сброс интервалов и сохранение в историю.

5. **История обслуживания**:
   - Хронологическая лента всех проведенных работ по каждому аппарату или по всему гаражу с указанием затрат и расходников.

6. **100% Офлайн и резервное копирование**:
   - Сохранение в `localStorage` браузера — приложение работает без интернета в подземном боксе или на лодочной станции.
   - Экспорт и импорт базы данных в один клик (JSON).

## Запуск приложения

```bash
cd moto-ledger
npm run dev
```

Приложение запустится на:
`http://localhost:3000` (или `http://127.0.0.1:3000`)

### Как открыть на смартфоне в гараже / домашней сети:
1. Убедитесь, что телефон подключен к тому же Wi-Fi.
2. Узнайте локальный IP компьютера (напр. `192.168.1.50`).
3. Запустите:
   ```bash
   npx next dev -H 0.0.0.0
   ```
4. Откройте в Safari / Chrome на телефоне: `http://<IP-компьютера>:3000`
5. В Safari нажмите **«Поделиться» → «На экран Домой»** (Add to Home Screen). Приложение установится как отдельное мобильное приложение на весь экран без рамок браузера.

## 🐳 Развертывание на публичном сервере (Docker)

Для запуска на публичном хосте подготовлен легковесный Docker-образ (~140 МБ) с поддержкой Docker Compose, Caddy и Nginx:

```bash
# 1. Запуск через Docker Compose
docker compose up -d --build

# 2. Проверка статуса
docker compose ps
```

Подробные инструкции по настройке домена, SSL/HTTPS (Let's Encrypt), Caddy, Nginx и облачных PaaS см. в [DEPLOY.md](DEPLOY.md).
